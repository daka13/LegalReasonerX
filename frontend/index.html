How It Works

From citation to comprehensive analysis in four simple steps

01

Enter a Citation

Start by entering a legal citation (e.g., "520 U.S. 17"). The system verifies the citation and extracts all related precedent cases automatically.

02

Visualize the Network

View the citation network to see how cases reference each other. The interactive D3.js visualization helps you understand complex legal relationships.

03

Analyze Opinions

Read full legal opinions from both the base case and all cited precedents. Compare reasoning patterns and extract key insights effortlessly.

04

AI-Powered Analysis

Use GPT-4 to analyze how precedent cases support the legal argument. Get detailed reasoning analysis, entity extraction, and ratio decidendi identification.
