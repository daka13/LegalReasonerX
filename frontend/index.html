How It Works

1️⃣ Enter a Citation

Start by entering a legal citation (e.g., "179 U.S. 77") in the Citation Lookup tool. The system will verify the citation and extract all related precedent cases.

2️⃣ Visualize the Network

View the citation network to see how cases reference each other. The interactive visualization helps you understand complex legal relationships.

3️⃣ Analyze Opinions

Read full legal opinions from both the base case and all cited precedents. Compare reasoning patterns and extract key insights.

4️⃣ AI-Powered Analysis

Use AI to analyze how precedent cases support the legal argument in the base case. Get detailed reasoning analysis and entity extraction.
